## Introduction

Teleoperation allows remote control of robots. Shared autonomy combines human intent with robot intelligence for better performance.

<RAGZone id="introduction"></RAGZone>

## Theory Content

### Section 1: Teleoperation

Remote control through input devices (joysticks, motion capture). Challenges include latency and limited sensing.

### Section 2: Haptic Feedback

Force feedback devices let operators feel robot interactions, improving dexterity and safety.

### Section 3: Shared Autonomy

Robot assists human commands (collision avoidance, stabilization) while human provides high-level intent.

## Simulation Lab

```python
# Autonomy levels
levels = [
    ('Direct control', 'Human controls everything'),
    ('Safeguarded', 'Robot prevents collisions'),
    ('Shared', 'Robot assists with execution'),
    ('Supervised', 'Robot acts, human monitors'),
    ('Full autonomy', 'Robot decides and acts')
]
print("Autonomy Levels:")
for name, desc in levels:
    print(f"  {name}: {desc}")
```

## Quiz

### Question 1
Teleoperation means?
A) Autonomous operation B) Remote control by human C) No control D) Random motion
<details><summary>Answer</summary>**B**: Teleoperation is human remote control of robots.</details>

### Question 2
Haptic feedback provides?
A) Visual display B) Force sensation to operator C) Sound only D) Temperature
<details><summary>Answer</summary>**B**: Haptics let operators feel forces the robot experiences.</details>

### Question 3
Shared autonomy combines?
A) Two robots B) Human intent and robot assistance C) No assistance D) Full automation
<details><summary>Answer</summary>**B**: Human provides intent while robot assists execution.</details>

### Question 4
Latency in teleoperation causes?
A) Better control B) Delayed response C) Faster motion D) Lower power
<details><summary>Answer</summary>**B**: Communication delay makes remote control harder.</details>

### Question 5
Surgical robots use?
A) Full autonomy B) Teleoperation with enhancement C) No control D) Random motion
<details><summary>Answer</summary>**B**: Surgical robots combine teleoperation with motion scaling and filtering.</details>
