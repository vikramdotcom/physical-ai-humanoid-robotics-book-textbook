## Introduction

Manipulation planning combines grasp planning with motion planning to accomplish tasks like picking up objects and placing them.

<RAGZone id="introduction"></RAGZone>

---

## Theory Content

### Section 1: Pick-and-Place

The basic manipulation sequence: approach, grasp, lift, transport, lower, release. Each phase requires planning.

### Section 2: Motion Primitives

Reusable motion patterns (reach, grasp, lift) that can be combined for complex tasks.

### Section 3: Task Planning

High-level planning decomposes goals into manipulation sequences using symbolic reasoning.

## Quiz

### Question 1
Pick-and-place includes?
A) Only picking B) Approach, grasp, transport, place C) Only placing D) No motion
<details><summary>Answer</summary>**B**: Complete operation includes all phases from approach to release.</details>

### Question 2
Motion primitives are?
A) Random motions B) Reusable motion patterns C) Single joint moves D) No motion
<details><summary>Answer</summary>**B**: Primitives are reusable building blocks for complex tasks.</details>

### Question 3
Task planning uses?
A) Random selection B) Symbolic reasoning C) No planning D) Manual control only
<details><summary>Answer</summary>**B**: Task planning reasons about goal decomposition symbolically.</details>

### Question 4
Pre-grasp pose is?
A) After grasping B) Position before closing gripper C) Final position D) Home position
<details><summary>Answer</summary>**B**: Pre-grasp positions the gripper before closing on the object.</details>

### Question 5
MoveIt2 provides?
A) Only visualization B) Motion and manipulation planning C) Power management D) Network configuration
<details><summary>Answer</summary>**B**: MoveIt2 is a comprehensive motion planning framework.</details>
