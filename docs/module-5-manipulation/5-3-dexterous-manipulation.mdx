## Introduction

Dexterous manipulation moves objects within the hand, enabling reorientation and precise positioning without regrasping.

<RAGZone id="introduction"></RAGZone>

---

## Theory Content

### Section 1: In-Hand Manipulation

Rotating and translating objects within a grasp using coordinated finger motions.

### Section 2: Finger Gaiting

Fingers take turns maintaining grasp while others reposition, enabling large reorientations.

### Section 3: Tool Use

Using objects as tools (hammers, screwdrivers) extends robot capabilities beyond direct manipulation.

## Quiz

### Question 1
In-hand manipulation means?
A) Picking up objects B) Moving objects within the grasp C) Dropping objects D) No manipulation
<details><summary>Answer</summary>**B**: In-hand manipulation repositions objects without releasing.</details>

### Question 2
Finger gaiting involves?
A) Walking B) Alternating finger contacts for reorientation C) No fingers D) Single finger only
<details><summary>Answer</summary>**B**: Fingers alternate contact to achieve large reorientations.</details>

### Question 3
Tool use extends?
A) Robot size B) Manipulation capabilities C) Battery life D) Network range
<details><summary>Answer</summary>**B**: Tools extend what the robot can accomplish beyond direct manipulation.</details>

### Question 4
Dexterous hands have?
A) 1 DOF B) Many DOF (15+) C) No DOF D) Only 2 fingers
<details><summary>Answer</summary>**B**: Dexterous hands have many DOF for complex manipulation.</details>

### Question 5
OpenAI cube manipulation used?
A) Only simulation B) Reinforcement learning C) No learning D) Manual programming only
<details><summary>Answer</summary>**B**: RL with sim-to-real enabled complex dexterous manipulation.</details>
