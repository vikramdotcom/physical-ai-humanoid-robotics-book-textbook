## Theory Content

### Section 1: Grasp Types

**Power grasp**: Maximum contact area and force (holding a hammer).
**Precision grasp**: Fingertip control for dexterity (holding a pen).

### Section 2: Force and Form Closure

**Force closure**: Grasp can resist any external wrench through friction.
**Form closure**: Geometry alone prevents motion (needs more contacts).

### Section 3: Grasp Planning

Select contact points and forces to achieve stable grasps. Consider object shape, weight, and task requirements.

## Simulation Lab

```python
import numpy as np
# Simple force closure check (2D, two fingers)
mu = 0.5  # Friction coefficient
finger_force = 10  # N each

# Can hold against vertical load?
max_friction = 2 * mu * finger_force
weight = 8  # N
print(f"Max friction: {max_friction} N, Object weight: {weight} N")
print(f"Grasp stable: {max_friction >= weight}")
```

## Quiz

### Question 1
Power grasp is for?
A) Precision B) Maximum force and stability C) Small objects only D) No contact
<details><summary>Answer</summary>**B**: Power grasps maximize contact for secure, forceful holding.</details>

### Question 2
Force closure requires?
A) No friction B) Friction at contacts C) Form only D) No contacts
<details><summary>Answer</summary>**B**: Force closure uses friction to resist external forces.</details>

### Question 3
Grasp planning selects?
A) Robot color B) Contact points and forces C) Battery type D) Network settings
<details><summary>Answer</summary>**B**: Planning determines where and how to grasp objects.</details>

### Question 4
Precision grasp uses?
A) Full hand B) Fingertips for fine control C) No contact D) Suction only
<details><summary>Answer</summary>**B**: Precision grasps use fingertips for dexterous manipulation.</details>

### Question 5
Form closure means?
A) Using friction B) Geometry alone prevents motion C) Weak grasp D) No grasp
<details><summary>Answer</summary>**B**: Form closure uses object geometry to constrain motion.</details>
