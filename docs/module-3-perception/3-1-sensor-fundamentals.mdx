## Introduction

Sensors are the robot's connection to the physical world, converting physical phenomena into electrical signals. Understanding sensor fundamentals is essential for building effective robotic perception systems.

<RAGZone id="introduction"></RAGZone>

---

## Theory Content

### Section 1: Sensor Classification

**Exteroceptive sensors** perceive the external environment (cameras, LIDAR, sonar). **Proprioceptive sensors** measure internal state (encoders, IMUs, current sensors).

### Section 2: Key Specifications

- **Range**: Minimum and maximum measurable values
- **Resolution**: Smallest detectable change
- **Accuracy**: Closeness to true value
- **Precision**: Repeatability of measurements
- **Bandwidth**: Response speed

### Section 3: Noise and Calibration

All sensors have noise. Understanding and mitigating noise through filtering and calibration is crucial for reliable robot operation.

## Simulation Lab

```python
import numpy as np
import matplotlib.pyplot as plt

# Simulate noisy sensor readings
true_value = 10.0
noise_std = 0.5
readings = true_value + np.random.normal(0, noise_std, 100)

plt.figure(figsize=(10, 4))
plt.plot(readings, 'b.', alpha=0.5, label='Readings')
plt.axhline(y=true_value, color='r', linestyle='--', label='True value')
plt.xlabel('Sample')
plt.ylabel('Value')
plt.legend()
plt.title('Simulated Sensor Noise')
plt.show()
```

## Quiz

### Question 1
What does sensor resolution measure?
A) Maximum range B) Smallest detectable change C) Speed D) Cost
<details><summary>Answer</summary>**B**: Resolution is the smallest change the sensor can detect.</details>

### Question 2
What type of sensor measures internal robot state?
A) Exteroceptive B) Proprioceptive C) External D) Visual
<details><summary>Answer</summary>**B**: Proprioceptive sensors measure internal state like joint positions.</details>

### Question 3
Why is calibration important?
A) Reduces cost B) Improves accuracy C) Increases speed D) Adds features
<details><summary>Answer</summary>**B**: Calibration corrects systematic errors to improve measurement accuracy.</details>

### Question 4
What is sensor bandwidth?
A) Data size B) Response speed C) Power consumption D) Cost
<details><summary>Answer</summary>**B**: Bandwidth indicates how quickly the sensor can respond to changes.</details>

### Question 5
How is noise typically reduced?
A) Ignore it B) Filtering C) Higher voltage D) Larger sensors
<details><summary>Answer</summary>**B**: Filtering techniques like averaging or Kalman filters reduce noise effects.</details>
