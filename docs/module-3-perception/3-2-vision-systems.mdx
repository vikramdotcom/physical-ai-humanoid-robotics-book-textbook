## Introduction

Vision systems give robots the ability to see and understand their environment. From simple cameras to sophisticated LiDAR systems, each technology has unique strengths for different applications.

<RAGZone id="introduction"></RAGZone>

---

## Theory Content

### Section 1: Camera Technologies

**RGB Cameras**: Standard color imaging for object recognition and navigation. **Monochrome Cameras**: Higher sensitivity, often used in industrial applications. **Event Cameras**: Capture changes asynchronously for high-speed applications.

### Section 2: Depth Sensing

**Stereo Vision**: Two cameras compute depth from disparity. **Structured Light**: Project patterns to measure depth (Intel RealSense). **Time-of-Flight**: Measure light travel time (Microsoft Kinect).

### Section 3: LiDAR

LiDAR uses laser light to create precise 3D maps. Types include spinning LiDAR (Velodyne), solid-state LiDAR, and MEMS-based systems.

## Simulation Lab

```python
import numpy as np
import matplotlib.pyplot as plt

# Simulate stereo depth calculation
baseline = 0.1  # meters
focal_length = 500  # pixels
disparity = np.linspace(1, 100, 100)
depth = (baseline * focal_length) / disparity

plt.figure(figsize=(10, 5))
plt.plot(disparity, depth)
plt.xlabel('Disparity (pixels)')
plt.ylabel('Depth (meters)')
plt.title('Stereo Vision: Depth vs Disparity')
plt.grid(True)
plt.show()
```

## Quiz

### Question 1
What principle does stereo vision use?
A) Time of flight B) Disparity between two views C) Structured light D) Radar
<details><summary>Answer</summary>**B**: Stereo vision computes depth from the disparity between two camera views.</details>

### Question 2
What is an advantage of LiDAR?
A) Low cost B) Precise 3D measurements C) Works in darkness only D) No calibration needed
<details><summary>Answer</summary>**B**: LiDAR provides precise 3D distance measurements.</details>

### Question 3
Structured light depth sensing works by?
A) Measuring sound B) Projecting known patterns C) Using GPS D) Temperature sensing
<details><summary>Answer</summary>**B**: Structured light projects known patterns and analyzes distortions.</details>

### Question 4
What limits stereo vision accuracy at long range?
A) Color accuracy B) Disparity becomes very small C) Power consumption D) Size
<details><summary>Answer</summary>**B**: At long range, disparity becomes small and harder to measure accurately.</details>

### Question 5
Event cameras excel at?
A) Color accuracy B) High-speed motion capture C) Low light D) Cost
<details><summary>Answer</summary>**B**: Event cameras capture changes asynchronously, ideal for high-speed motion.</details>
