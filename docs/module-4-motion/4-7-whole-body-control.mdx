## Introduction

Humanoid robots have many DOF that must work together. Whole-body control coordinates all joints to achieve multiple simultaneous objectives.

<RAGZone id="introduction"></RAGZone>

---

## Theory Content

### Section 1: Task Prioritization

Multiple tasks (balance, manipulation, gaze) compete for robot DOF. Task priority frameworks assign importance and resolve conflicts.

### Section 2: Null Space Control

Higher-priority tasks use DOF first. Lower-priority tasks use remaining DOF (null space) without affecting higher tasks.

### Section 3: Compliance

Compliance allows the robot to yield to external forces, enabling safe interaction and robust manipulation.

import numpy as np

print("Task Hierarchy:")

## Quiz

### Question 1
Whole-body control coordinates?
A) One joint B) All robot DOF C) Only arms D) Only legs
<details><summary>Answer</summary>**B**: WBC coordinates all degrees of freedom simultaneously.</details>

### Question 2
Task prioritization resolves?
A) Power issues B) Conflicts between multiple objectives C) Cost D) Weight
<details><summary>Answer</summary>**B**: Priority frameworks decide which tasks get DOF when they conflict.</details>

### Question 3
Null space is used for?
A) Primary tasks B) Lower-priority tasks without affecting higher ones C) Nothing D) Power
<details><summary>Answer</summary>**B**: Null space motions don't affect higher-priority task performance.</details>

### Question 4
Compliance enables?
A) Rigidity B) Safe interaction with forces C) Faster motion D) Heavier loads
<details><summary>Answer</summary>**B**: Compliant control allows yielding to external forces for safety.</details>

### Question 5
Atlas parkour requires?
A) Simple control B) Whole-body coordination C) Single joint control D) No control
<details><summary>Answer</summary>**B**: Complex maneuvers need coordinated whole-body control.</details>
