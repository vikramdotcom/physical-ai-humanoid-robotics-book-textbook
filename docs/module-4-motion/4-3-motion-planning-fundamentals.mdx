## Introduction

Motion planning finds collision-free paths from start to goal configurations. It's essential for robots operating in cluttered environments.

<RAGZone id="introduction"></RAGZone>

---

## Theory Content

### Section 1: Configuration Space

C-space represents all possible robot configurations. Obstacles map to C-space obstacles. Planning happens in C-space.

### Section 2: Planning Algorithms

**RRT (Rapidly-exploring Random Trees)**: Samples random configurations and grows a tree toward them.
**PRM (Probabilistic Roadmap)**: Builds a graph of valid configurations for repeated queries.
**A***: Graph search with heuristics for optimal paths.

### Section 3: Trajectory Optimization

Convert paths to smooth, time-parameterized trajectories respecting velocity and acceleration limits.

## Simulation Lab

```python
import numpy as np
import matplotlib.pyplot as plt

# Simple RRT visualization concept
np.random.seed(42)
nodes = [(0, 0)]  # Start
goal = (9, 9)

for _ in range(100):
    # Random sample
    sample = (np.random.uniform(0, 10), np.random.uniform(0, 10))
    # Find nearest (simplified)
    nearest = min(nodes, key=lambda n: (n[0]-sample[0])**2 + (n[1]-sample[1])**2)
    # Extend toward sample
    direction = np.array(sample) - np.array(nearest)
    direction = direction / (np.linalg.norm(direction) + 0.001)
    new_node = tuple(np.array(nearest) + direction * 0.5)
    nodes.append(new_node)

plt.figure(figsize=(8, 8))
for i, node in enumerate(nodes[1:], 1):
    plt.plot([nodes[i-1][0], node[0]], [nodes[i-1][1], node[1]], 'b-', alpha=0.3)
plt.plot(0, 0, 'go', markersize=15, label='Start')
plt.plot(*goal, 'r*', markersize=15, label='Goal')
plt.legend()
plt.title('RRT Tree Growth')
plt.show()
```

## Quiz

### Question 1
Configuration space represents?
A) Physical space B) All possible robot configurations C) Sensor data D) Time
<details><summary>Answer</summary>**B**: C-space contains all possible configurations of the robot.</details>

### Question 2
RRT stands for?
A) Real-time Routing B) Rapidly-exploring Random Tree C) Robot Route Tracker D) Reverse Rotation Transform
<details><summary>Answer</summary>**B**: Rapidly-exploring Random Trees grow toward random samples.</details>

### Question 3
Why plan in C-space?
A) Faster B) Obstacles become points/regions C) More colorful D) Simpler math
<details><summary>Answer</summary>**B**: In C-space, robot collision checking becomes point-in-region tests.</details>

### Question 4
PRM is suited for?
A) Single queries B) Multiple queries in same environment C) Moving obstacles D) Real-time only
<details><summary>Answer</summary>**B**: PRM builds a reusable roadmap for repeated planning queries.</details>

### Question 5
Trajectory optimization adds?
A) Colors B) Time parameterization and smoothness C) More obstacles D) Sensors
<details><summary>Answer</summary>**B**: Trajectory optimization creates smooth, timed motions from geometric paths.</details>
