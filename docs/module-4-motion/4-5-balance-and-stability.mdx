## Introduction

Balance keeps robots upright. Static balance maintains CoM over support; dynamic balance uses momentum and stepping strategies.

<RAGZone id="introduction"></RAGZone>

---

## Theory Content

### Section 1: Static vs Dynamic Balance

**Static**: CoM projection stays within support polygon. Works for slow motion.
**Dynamic**: Uses momentum; CoM can temporarily leave support. Enables faster motion.

### Section 2: Push Recovery

Strategies include ankle strategy (small pushes), hip strategy (medium), and stepping strategy (large disturbances).

## Simulation Lab

```python
import numpy as np
import matplotlib.pyplot as plt

# Inverted pendulum balance simulation
dt = 0.01
time = np.arange(0, 5, dt)
theta = np.zeros_like(time)
theta_dot = np.zeros_like(time)
theta[0] = 0.1  # Initial tilt

g, L = 9.81, 1.0
Kp, Kd = 50, 10  # PD gains

for i in range(1, len(time)):
    # Control torque (PD)
    tau = -Kp*theta[i-1] - Kd*theta_dot[i-1]
    # Dynamics
    theta_ddot = g/L * np.sin(theta[i-1]) + tau
    theta_dot[i] = theta_dot[i-1] + theta_ddot * dt
    theta[i] = theta[i-1] + theta_dot[i] * dt

plt.figure(figsize=(10, 4))
plt.plot(time, np.degrees(theta))
plt.xlabel('Time (s)')
plt.ylabel('Angle (degrees)')
plt.title('Balance Control: Inverted Pendulum')
plt.grid(True)
plt.show()
```

## Quiz

### Question 1
Static balance requires?
A) Running B) CoM over support polygon C) Falling D) Jumping
<details><summary>Answer</summary>**B**: Static balance keeps CoM projection within the support base.</details>

### Question 2
Ankle strategy handles?
A) Large pushes B) Small disturbances C) Running D) Jumping
<details><summary>Answer</summary>**B**: Ankle torques correct small balance disturbances.</details>

### Question 3
Stepping strategy is for?
A) Small pushes B) Large disturbances C) Standing still D) Sleeping
<details><summary>Answer</summary>**B**: Taking a step recovers from larger pushes.</details>

### Question 4
Dynamic balance allows?
A) Only standing B) CoM to temporarily leave support C) Slower motion D) No motion
<details><summary>Answer</summary>**B**: Dynamic balance uses momentum, allowing temporary imbalance.</details>

### Question 5
Push recovery uses?
A) Random motion B) Reactive control strategies C) Ignoring pushes D) Falling over
<details><summary>Answer</summary>**B**: Push recovery employs control strategies to maintain balance.</details>
