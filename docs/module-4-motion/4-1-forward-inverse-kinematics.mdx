## Introduction

Kinematics describes robot motion without considering forces. Forward kinematics finds end effector position from joint angles; inverse kinematics finds joint angles to reach a position.

<RAGZone id="introduction"></RAGZone>

---

## Theory Content

### Section 1: Forward Kinematics

Given joint angles θ₁, θ₂, ..., θₙ, compute end effector pose using transformation matrices or DH parameters.

### Section 2: Inverse Kinematics

Given desired end effector pose, find joint angles. May have multiple solutions, one solution, or no solution.

### Section 3: Solution Methods

**Analytical**: Closed-form solutions for specific robot geometries.
**Numerical**: Iterative methods (Jacobian, gradient descent) for general cases.

## Simulation Lab

```python
import numpy as np
import matplotlib.pyplot as plt

def forward_kinematics_2link(theta1, theta2, L1=1, L2=1):
    x = L1*np.cos(theta1) + L2*np.cos(theta1+theta2)
    y = L1*np.sin(theta1) + L2*np.sin(theta1+theta2)
    return x, y

def inverse_kinematics_2link(x, y, L1=1, L2=1):
    c2 = (x**2 + y**2 - L1**2 - L2**2) / (2*L1*L2)
    if abs(c2) > 1: return None, None
    theta2 = np.arccos(c2)
    theta1 = np.arctan2(y, x) - np.arctan2(L2*np.sin(theta2), L1+L2*np.cos(theta2))
    return theta1, theta2

# Test IK
target = (1.2, 0.8)
t1, t2 = inverse_kinematics_2link(*target)
if t1 is not None:
    x, y = forward_kinematics_2link(t1, t2)
    print(f"Target: {target}, Achieved: ({x:.3f}, {y:.3f})")
```

## Quiz

### Question 1
Forward kinematics computes?
A) Forces B) End effector pose from joint angles C) Joint angles from pose D) Velocity
<details><summary>Answer</summary>**B**: FK finds end effector position given joint angles.</details>

### Question 2
IK may have?
A) Always one solution B) Multiple, one, or no solutions C) Only numerical solutions D) Only analytical solutions
<details><summary>Answer</summary>**B**: IK can have multiple valid solutions or none if unreachable.</details>

### Question 3
Jacobian methods are?
A) Analytical B) Numerical/iterative C) Exact D) Only for 2-link arms
<details><summary>Answer</summary>**B**: Jacobian-based IK uses iterative numerical approaches.</details>

### Question 4
Why prefer analytical IK?
A) More flexible B) Faster computation C) Works for all robots D) Simpler code
<details><summary>Answer</summary>**B**: Analytical solutions are faster when available.</details>

### Question 5
Redundant robots have?
A) No IK solution B) Exactly one IK solution C) Infinite IK solutions D) Only forward kinematics
<details><summary>Answer</summary>**C**: Redundant robots have extra DOF, giving infinite ways to reach a pose.</details>
