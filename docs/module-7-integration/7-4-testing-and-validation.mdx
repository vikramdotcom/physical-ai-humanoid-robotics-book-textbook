## Theory Content

### Unit Testing
Test individual components in isolation.

### Integration Testing
Test component interactions and interfaces.

### Hardware-in-the-Loop (HIL)
Test software with real hardware components.

## Quiz

### Question 1
Unit tests check?
A) Whole system B) Individual components C) Network D) Power
<details><summary>Answer</summary>**B**: Unit tests verify individual components work correctly.</details>

### Question 2
Integration tests verify?
A) Single functions B) Component interactions C) Hardware only D) Nothing
<details><summary>Answer</summary>**B**: Integration tests check that components work together.</details>

### Question 3
HIL stands for?
A) High Integration Level B) Hardware-in-the-Loop C) Hybrid Interface Logic D) Host Input Layer
<details><summary>Answer</summary>**B**: HIL tests software with real hardware.</details>

### Question 4
Testing pyramid has more?
A) System tests B) Unit tests at base C) Equal all levels D) No tests
<details><summary>Answer</summary>**B**: Many unit tests, fewer higher-level tests.</details>

### Question 5
Why test in simulation first?
A) Required by law B) Safe and fast C) Not useful D) More expensive
<details><summary>Answer</summary>**B**: Simulation testing is safe and faster than real-world.</details>
