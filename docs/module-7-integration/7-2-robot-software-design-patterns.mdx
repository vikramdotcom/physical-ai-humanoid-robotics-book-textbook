## Theory Content

### State Machines
States and transitions model discrete robot behaviors. Simple but limited scalability.

### Behavior Trees
Tree structure combining sequences, selectors, and actions. Modular and reactive.

### Modular Design
Separate perception, planning, and control for maintainability.

## Quiz

### Question 1
State machines have?
A) No states B) States and transitions C) Only transitions D) Continuous flow
<details><summary>Answer</summary>**B**: FSMs define discrete states connected by transitions.</details>

### Question 2
Behavior trees are?
A) Linear B) Hierarchical and modular C) Random D) Single node
<details><summary>Answer</summary>**B**: BTs use tree structure for modular behavior composition.</details>

### Question 3
Modular design separates?
A) Nothing B) Perception, planning, control C) Only hardware D) Only software
<details><summary>Answer</summary>**B**: Modularity separates concerns for maintainability.</details>

### Question 4
BT selector nodes?
A) Run all children B) Try children until one succeeds C) Never run D) Run randomly
<details><summary>Answer</summary>**B**: Selectors try alternatives until one succeeds.</details>

### Question 5
BT sequence nodes?
A) Run randomly B) Run children in order C) Never run D) Skip all
<details><summary>Answer</summary>**B**: Sequences execute children in order.</details>
