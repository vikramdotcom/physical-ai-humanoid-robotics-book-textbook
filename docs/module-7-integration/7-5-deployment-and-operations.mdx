## Theory Content

### Edge Computing
Run AI and control on robot hardware for low latency and reliability.

### Fleet Management
Coordinate multiple robots with centralized monitoring and task assignment.

### Monitoring and Logging
Track performance, detect issues, and enable debugging.

## Quiz

### Question 1
Edge computing runs AI?
A) Only in cloud B) On robot hardware C) Nowhere D) Only in simulation
<details><summary>Answer</summary>**B**: Edge computing processes data locally on robots.</details>

### Question 2
Fleet management coordinates?
A) One robot B) Multiple robots C) No robots D) Only simulation
<details><summary>Answer</summary>**B**: Fleet management handles multiple robots.</details>

### Question 3
Monitoring helps with?
A) Nothing B) Issue detection C) Hardware design D) Initial development
<details><summary>Answer</summary>**B**: Monitoring detects problems in deployed systems.</details>

### Question 4
OTA stands for?
A) On The Air B) Over-the-Air (updates) C) Only Testing Allowed D) Open Technical Access
<details><summary>Answer</summary>**B**: OTA enables remote software updates.</details>

### Question 5
Why log robot data?
A) Not useful B) Debugging and improvement C) Required by law only D) Storage practice
<details><summary>Answer</summary>**B**: Logs enable debugging and system improvement.</details>
