## Introduction

ROS2 is the standard framework for robot software. Understanding its architecture enables building scalable, maintainable robotic systems.

<RAGZone id="introduction"></RAGZone>

## Theory Content

### Nodes
Independent processes performing specific functions. Promote modularity and reuse.

### Topics
Pub/sub channels for streaming data (sensor readings, commands).

### Services
Synchronous request/response for queries and commands.

### Actions
Long-running tasks with feedback and cancellation.

<RAGZone id="theory-content"></RAGZone>

## Quiz

### Question 1
Topics are for?
A) One-time queries B) Streaming data C) Long tasks D) Storage
<details><summary>Answer</summary>**B**: Topics stream continuous data.</details>

### Question 2
Services provide?
A) Streaming B) Request-response C) File storage D) Network config
<details><summary>Answer</summary>**B**: Services handle synchronous requests.</details>

### Question 3
Actions support?
A) Only start B) Start, feedback, cancel C) Storage only D) No feedback
<details><summary>Answer</summary>**B**: Actions provide feedback and cancellation for long tasks.</details>

### Question 4
Nodes promote?
A) Monolithic code B) Modularity C) Single process D) No structure
<details><summary>Answer</summary>**B**: Nodes enable modular, reusable code.</details>

### Question 5
ROS2 uses which middleware?
A) HTTP B) DDS C) FTP D) SMTP
<details><summary>Answer</summary>**B**: ROS2 uses DDS (Data Distribution Service).</details>
