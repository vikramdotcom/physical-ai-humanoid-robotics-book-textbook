## Introduction

RL learns optimal behavior through trial and error, receiving rewards for good actions—ideal for robot control.

<RAGZone id="introduction"></RAGZone>

## Theory Content

### Markov Decision Process (MDP)
States, actions, transitions, rewards define the RL problem.

### Policy and Value Functions
Policy maps states to actions; value functions estimate expected rewards.

### Q-Learning
Model-free algorithm learning action values directly.

<RAGZone id="theory-content"></RAGZone>

## Quiz

### Question 1
MDP stands for?
A) Machine Data Protocol B) Markov Decision Process C) Motor Drive Power D) Manual Design Pattern
<details><summary>Answer</summary>**B**: MDP is the mathematical framework for RL.</details>

### Question 2
Q-learning learns?
A) Policy directly B) Action values C) Only states D) Hardware
<details><summary>Answer</summary>**B**: Q-learning learns Q-values (action values).</details>

### Question 3
Reward signal indicates?
A) Hardware status B) Quality of actions C) Battery level D) Network speed
<details><summary>Answer</summary>**B**: Rewards guide learning toward good behavior.</details>

### Question 4
Policy defines?
A) Hardware specs B) Mapping from states to actions C) Network protocol D) Power management
<details><summary>Answer</summary>**B**: Policy specifies which action to take in each state.</details>

### Question 5
RL requires?
A) Only labeled data B) Interaction with environment C) No computation D) Manual tuning only
<details><summary>Answer</summary>**B**: RL learns through environment interaction.</details>
