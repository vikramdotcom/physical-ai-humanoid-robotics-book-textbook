## Quiz

### Question 1
Data quality affects?
A) Nothing B) Learning success C) Robot color D) Network speed
<details><summary>Answer</summary>**B**: High-quality data is essential for successful learning.</details>

### Question 2
Teleoperation collects data through?
A) Autonomy only B) Human control C) No control D) Random motion
<details><summary>Answer</summary>**B**: Humans control robots to collect demonstration data.</details>

### Question 3
Evaluation metrics measure?
A) Robot weight B) Learning success C) Cost only D) Size
<details><summary>Answer</summary>**B**: Metrics quantify how well the system performs.</details>

### Question 4
Training infrastructure includes?
A) Only software B) Compute and frameworks C) Only hardware D) Nothing
<details><summary>Answer</summary>**B**: Infrastructure includes compute resources and software frameworks.</details>

### Question 5
Real-world testing is important because?
A) Fun B) Validates simulation results C) Required by law D) Saves cost
<details><summary>Answer</summary>**B**: Real testing validates that learning transfers to deployment.</details>
