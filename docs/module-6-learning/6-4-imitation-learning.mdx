## Introduction

Imitation learning lets robots learn by watching experts, avoiding the need for manual reward design.

<RAGZone id="introduction"></RAGZone>

## Theory Content

### Behavioral Cloning
Directly learn policy from state-action pairs in demonstrations.

### Inverse RL
Infer reward function from expert behavior, then optimize.

### DAgger
Dataset Aggregation iteratively improves by querying expert on robot's visited states.

## Quiz

### Question 1
Behavioral cloning learns from?
A) Random data B) Expert demonstrations C) No data D) Hardware specs
<details><summary>Answer</summary>**B**: BC learns directly from expert state-action pairs.</details>

### Question 2
Inverse RL infers?
A) Policy B) Reward function C) Hardware D) Network
<details><summary>Answer</summary>**B**: IRL recovers the reward function from demonstrations.</details>

### Question 3
DAgger addresses?
A) Hardware issues B) Distribution shift C) Power management D) Communication
<details><summary>Answer</summary>**B**: DAgger handles the distribution shift problem in BC.</details>

### Question 4
Imitation learning requires?
A) No expert B) Expert demonstrations C) Only simulation D) No learning
<details><summary>Answer</summary>**B**: IL needs demonstrations from experts.</details>

### Question 5
Advantage of imitation learning?
A) No data needed B) Avoids reward engineering C) Faster hardware D) Less computation
<details><summary>Answer</summary>**B**: IL doesn't require designing reward functions.</details>
