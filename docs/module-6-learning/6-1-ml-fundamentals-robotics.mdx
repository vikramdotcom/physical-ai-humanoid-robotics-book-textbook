## Introduction

Machine learning enables robots to learn from data rather than explicit programming, essential for handling real-world complexity.

<RAGZone id="introduction"></RAGZone>

## Theory Content

### Supervised Learning
Learn from labeled examples (input-output pairs).

### Unsupervised Learning
Find patterns in unlabeled data.

### Neural Networks
Computational models inspired by biological neurons, powerful for perception and control.

## Quiz

### Question 1
Supervised learning requires?
A) No data B) Labeled examples C) Only images D) Hardware
<details><summary>Answer</summary>**B**: Supervised learning uses labeled input-output pairs.</details>

### Question 2
Neural networks are inspired by?
A) Cars B) Biological neurons C) Wheels D) Gears
<details><summary>Answer</summary>**B**: Neural networks mimic brain structure.</details>

### Question 3
ML for robotics enables?
A) Manual control only B) Learning from data C) No adaptation D) Fixed behavior
<details><summary>Answer</summary>**B**: ML enables data-driven learning and adaptation.</details>

### Question 4
Unsupervised learning finds?
A) Labels B) Patterns without labels C) Exact answers D) Hardware faults
<details><summary>Answer</summary>**B**: Unsupervised learning discovers patterns in unlabeled data.</details>

### Question 5
Deep learning uses?
A) Shallow models B) Multi-layer neural networks C) No computation D) Only rules
<details><summary>Answer</summary>**B**: Deep learning uses deep (multi-layer) neural networks.</details>
