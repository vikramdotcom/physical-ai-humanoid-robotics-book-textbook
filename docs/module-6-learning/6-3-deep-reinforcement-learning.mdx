## Introduction

Deep RL combines neural networks with RL, enabling learning from high-dimensional inputs like images.

<RAGZone id="introduction"></RAGZone>

## Theory Content

### DQN
Deep Q-Networks use neural networks to approximate Q-functions for complex state spaces.

### Policy Gradients
Directly optimize policy parameters using gradient ascent on expected reward.

### Actor-Critic
Combines policy (actor) and value (critic) learning for stable, efficient training.

## Quiz

### Question 1
DQN uses neural networks for?
A) Hardware control B) Q-function approximation C) Power management D) Communication
<details><summary>Answer</summary>**B**: DQN approximates Q-values with neural networks.</details>

### Question 2
Policy gradients optimize?
A) Value function B) Policy parameters directly C) Hardware D) Network speed
<details><summary>Answer</summary>**B**: Policy gradients directly optimize policy parameters.</details>

### Question 3
Actor-critic combines?
A) Two robots B) Policy and value learning C) Hardware and software D) Networks
<details><summary>Answer</summary>**B**: Actor learns policy, critic estimates values.</details>

### Question 4
PPO stands for?
A) Power Protocol Output B) Proximal Policy Optimization C) Parallel Processing Order D) Protocol Port Option
<details><summary>Answer</summary>**B**: PPO is a popular actor-critic algorithm.</details>

### Question 5
Deep RL enables learning from?
A) Only labeled data B) High-dimensional inputs like images C) No data D) Hardware specs
<details><summary>Answer</summary>**B**: Deep RL can learn from complex sensory inputs.</details>
